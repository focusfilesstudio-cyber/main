# Claude Code Master Brief

## All Brands — Content Generation & Posting System

---

## GLOBAL RULES (Apply to ALL accounts)

- Posts must feel human, natural, and emotional — never robotic or AI-generated sounding
- Keep posts SHORT — 2 to 5 lines max unless specified otherwise
- Use 2 to 3 emojis per post maximum — placed naturally, never forced
- Never use hashtags unless explicitly told to
- CTA links go in the FIRST COMMENT only — never in the post body
- Rotate content types — never post the same type twice in a row
- Content pillars to rotate: Proof/flex, FOMO, relatable pain, them vs me, emotional/identity
- "Them vs me" format example: "they said digital products don't sell on Threads. me with $4k this month." — this is just an example, make variations
- Slight flex is encouraged — not bragging, just quiet confidence
- Debt-free, freedom, and lifestyle angles work well across all brands
- Never make posts sound like ads or sales pitches
- Emotional depth is required — every post should make someone feel something

## CONTENT GENERATION INSTRUCTIONS

When generating posts for a session:

1. Generate one post per scheduled time slot per account per day
2. Label each post clearly: Account name, time slot, post type (proof/FOMO/relatable/them vs me/identity)
3. Include a suggested first comment CTA where relevant
4. Rotate post types — never repeat the same type back to back
5. Keep all posts under 5 lines
6. Do not add hashtags
7. Do not explain or annotate the posts — just output them clean and ready to copy-paste
8. Format output as:

```
## [ACCOUNT NAME] — [TIME] — [POST TYPE]
[POST TEXT]
First comment: [CTA if applicable]
```

9. Generate posts that feel organic and human — vary sentence structure, vary emoji placement, vary capitalization style
10. Some posts should have no CTA at all — pure value or emotion only
